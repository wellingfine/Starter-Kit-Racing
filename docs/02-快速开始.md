# 02 - 快速开始

## 运行项目

1. 用 Godot 4.6 打开项目根目录下的 `project.godot`。
2. 等待资源导入完成（首次打开会生成 `.godot/imported/`）。
3. 按 <kbd>F5</kbd> 运行，主场景 `res://scenes/main.tscn` 会自动加载。

> 建议使用 Forward Plus 渲染器。项目设置中已写好，一般无需手动切换。

## 操作方式

| 按键 | 功能 |
| --- | --- |
| <kbd>W</kbd> | 加速 / 刹车 |
| <kbd>S</kbd> | 刹车 / 倒车 |
| <kbd>A</kbd> <kbd>D</kbd> | 转向 |

按键在 `project.godot` 的 `[input]` 段中定义为 `forward` / `back` / `left` / `right` 四个动作，同时绑定了手柄摇杆，详见 [项目设置](07-项目设置.md)。

## 编辑器操作步骤

### 调整赛道

1. 在场景树中选中 `GridMap` 节点。
2. 编辑器底部会切换到 GridMap 面板，从右侧的 MeshLibrary 里选择地块。
3. 在 3D 视口中点击摆放。

可用的地块包括：直线、弯道、坡道、颠簸路面、终点线、帐篷区，以及空地/森林/帐篷三种装饰件。

### 更换车辆模型

1. 展开 `Vehicle` → `Container`，删除现有的 `Model` 节点。
2. 从 `models/` 中拖入一个 `.glb`（例如 `vehicle-truck-yellow.glb`），作为 `Container` 的子节点。
3. 把该节点**重命名为 `Model`**（脚本按这个名字取节点）。

### 添加自定义车模

按上面的步骤操作，但模型必须包含以下子节点，否则对应特效不生效：

| 子节点名 | 用途 |
| --- | --- |
| `body` | 车身，用于加速俯仰与转向侧倾 |
| `wheel-front-left` | 左前轮 |
| `wheel-front-right` | 右前轮 |
| `wheel-back-left` | 左后轮 |
| `wheel-back-right` | 右后轮 |

> 脚本用 `get_node_or_null` 获取这些节点并全部判空，所以缺少轮子不会报错，只是没有车轮动画。

### 换成摩托车

1. 从主场景中删除 `Vehicle` 节点。
2. 把 `scenes/vehicle-motorcycle.tscn` 实例化到主场景中。
3. 选中 `View` 节点，在检查器中把 `target` 属性重新指向新的载具节点。
4. 如有需要，调整 `View` 节点的初始位置。

> `vehicle-motorcycle.tscn` 用的是 `scripts/vehicle-motorcycle.gd`，它继承自 `Vehicle`，只改了车身倾斜和车轮两处表现。

## 修改手感参数

所有手感参数都硬编码在 `scripts/vehicle.gd` 中，常用调整位置：

| 想改什么 | 改哪里 |
| --- | --- |
| 最高速度 | `linear_speed` 的 `lerp` 目标（`input.z`） |
| 转向灵敏度 | `target_angular` 中的系数 `4` |
| 转向响应速度 | `angular_speed` 的 `lerp` 系数 `delta * 4` |
| 抓地力 / 转向随速变化 | `steering_grip` 的 `clamp` 范围 |
| 刹车力度 | 刹车分支中的 `lerp(..., delta * 8)` |
| 相机距离 | `scripts/view.gd` 中 `target_z` 的 `remap` 区间 |

⚠️ 注意：物理球 `Sphere` 的 `gravity_scale`、`mass`、`angular_damp` 以及 `PhysicsMaterial` 的 `friction` 也会显著影响手感，这几项在 `scenes/vehicle.tscn` 里配置。
