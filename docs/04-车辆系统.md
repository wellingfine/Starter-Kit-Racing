# 04 - 车辆系统

这是整个项目最核心、最值得学习的部分。

## 一、为什么不用 `VehicleBody3D`

Godot 内置了 `VehicleBody3D` + `VehicleWheel3D`，但它参数多、调参难，高速下容易不稳定（官方故障排查文档也提到了这一点）。本项目**完全没用它**，而是自创了一套「球体代理」方案。

## 二、球体代理物理

### 节点结构

```
Vehicle (Node3D)              ← scripts/vehicle.gd
├── Ground    RayCast3D       ← 从球位置向下 0.7 探测地面法线
├── Container Node3D          ← 纯视觉层，跟随物理球
│   ├── Model                 车模型
│   ├── TrailLeft / TrailRight
│   └── ScreechSound / EngineSound / ImpactSound
└── Sphere    RigidBody3D     ← 唯一真正的物理体
```

`Sphere` 的关键配置（在 `scenes/vehicle.tscn` 中）：

| 属性 | 值 | 作用 |
| --- | --- | --- |
| `mass` | 1000.0 | 大质量带来沉稳感 |
| `gravity_scale` | 1.5 | 比常规重力更重，减少腾空 |
| `angular_damp` | 4.0（`mode=1` 替换模式） | 抑制球体乱转 |
| `linear_damp` | 0.1 | 轻微空气阻力 |
| `continuous_cd` | true | 高速防穿透 |
| `physics_material_override` | friction 5.0 / rough true | **关键**：靠高摩擦把自转转成位移 |
| `collision_layer` | 8 | 只与 layer 1（地面/GridMap）碰撞 |

### 驱动原理：给球加「角速度」而不是加「力」

这是整个方案最巧妙的地方。传统做法是 `apply_force` / `apply_central_force`，而这里是让球**自转**，靠球与地面的摩擦力把旋转转换成平移：

```119:119:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	sphere.angular_velocity += vehicle_model.get_global_transform().basis.x * (linear_speed * 100) * delta
```

注意旋转轴取的是 **`vehicle_model` 的 `basis.x`**（视觉模型的右向量），而不是球体自身的轴。这一行代码同时决定了两件事：

- 车往哪开 → 由模型朝向决定；
- 转向为什么是瞬时的 → 因为模型一转，驱动轴立刻跟着转。

### 转向：纯视觉旋转

```60:63:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	var target_angular = -input.x * steering_grip * 4 * direction
	angular_speed = lerp(angular_speed, target_angular, delta * 4)

	vehicle_model.rotate_y(angular_speed * delta)
```

转向**完全不经过物理系统**，只是旋转视觉模型。配合上面那行 `basis.x` 取轴，就得到了街机式的即时转向手感：

- 优点：响应快、手感干脆、无需调侧向摩擦参数；
- 代价：**没有真实的漂移与抓地力物理**，车不会侧滑。

转向幅度还随速度变化，低速时方向更「钝」，避免原地打转：

```58:58:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	var steering_grip = clamp(abs(linear_speed), 0.2, 1.0)
```

### 贴地对齐

`Ground`（RayCast3D）从球心向下 0.7 探测，取地面法线后重建模型的基向量，并插值 20% 平滑，避免在坡道/接缝处抖动：

```76:78:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
		if normal.dot(vehicle_model.global_basis.y) > 0.5:
			var xform = align_with_y(vehicle_model.global_transform, normal)
			vehicle_model.global_transform = vehicle_model.global_transform.interpolate_with(xform, 0.2).orthonormalized()
```

```180:185:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
func align_with_y(xform, new_y):

	xform.basis.y = new_y
	xform.basis.x = -xform.basis.z.cross(new_y)
	xform.basis = xform.basis.orthonormalized()
	return xform
```

`normal.dot(...) > 0.5` 这个判断是为了防止车翻过来或撞到垂直墙面时被强行「吸」到墙面上。

### 速度模型：一个虚拟标量

`linear_speed` **不是**物理速度，而是一个用 `lerp` 逼近输入的抽象值。这样可以把加速、刹车、倒车的手感拆开精细调节：

```84:90:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	if (target_speed < 0 and linear_speed > 0.01):
		linear_speed = lerp(linear_speed, 0.0, delta * 8)
	else:
		if (target_speed < 0):
			linear_speed = lerp(linear_speed, target_speed / 2, delta * 2)
		else:
			linear_speed = lerp(linear_speed, target_speed, delta * 6)
```

三个分支分别对应：**刹车**（前进中按 S，快速归零）、**倒车**（速度归零后以半速倒退）、**加速**。

另外还有一个 `acceleration`，它混入了球的角速度，用来驱动车轮旋转和车身俯仰：

```92:92:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	acceleration = lerpf(acceleration, linear_speed + (abs(sphere.angular_velocity.length() * linear_speed) / 100), delta * 1)
```

### 视觉层跟随物理球

```96:97:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	vehicle_model.position = sphere.position - Vector3(0, 0.65, 0)
	raycast.position = sphere.position
```

模型挂在球下方 0.65，射线始终跟着球走。

## 三、特效系统

`_physics_process` 末尾依次调用 4 个特效方法，它们都被设计成**可重写的扩展点**：

```106:109:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	effect_engine(delta)
	effect_body(delta)
	effect_wheels(delta)
	effect_trails()
```

### 引擎音效 `effect_engine`

同时用「速度」和「油门」两个因子驱动音量与音调，油门额外 +0.2 音调，制造换挡感：

```151:160:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	var speed_factor = clamp(abs(linear_speed), 0.0, 1.0)
	var throttle_factor = clamp(abs(input.z), 0.0, 1.0)

	var target_volume = remap(speed_factor + (throttle_factor * 0.5), 0.0, 1.5, -15.0, -5.0)
	engine_sound.volume_db = lerp(engine_sound.volume_db, target_volume, delta * 5.0)

	var target_pitch = remap(speed_factor, 0.0, 1.0, 0.5, 3)
	if throttle_factor > 0.1: target_pitch += 0.2

	engine_sound.pitch_scale = lerp(engine_sound.pitch_scale, target_pitch, delta * 2.0)
```

### 车身姿态 `effect_body`

- `rotation.x`：加速抬头 / 刹车点头，取 `-(linear_speed - acceleration) / 6`；
- `rotation.z`：转向侧倾 `calculated_lean`；
- `position`：向 `Vector3(0, 0.2, 0)` 缓慢回弹（配合落地时的弹跳）。

### 车轮 `effect_wheels`

四个轮子绕 X 轴自转（速度取 `acceleration`），两个前轮额外绕 Y 轴转向。

### 烟雾与打滑声 `effect_trails`

漂移强度是一个综合指标，超过 0.25 才触发：

```166:176:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
	var drift_intensity = abs(linear_speed - acceleration) + (abs(calculated_lean) * 2.0)
	var should_emit = drift_intensity > 0.25

	if trail_left != null: trail_left.emitting = should_emit
	if trail_right != null: trail_right.emitting = should_emit

	var target_volume = -80.0
	if should_emit: target_volume = remap(clamp(drift_intensity, 0.25, 2.0), 0.25, 2.0, -10.0, 0.0)

	screech_sound.pitch_scale = lerp(screech_sound.pitch_scale, clamp(abs(linear_speed), 1.0, 3.0), 0.1)
	screech_sound.volume_db = lerp(screech_sound.volume_db, target_volume, 10.0 * get_physics_process_delta_time())
```

`abs(linear_speed - acceleration)` 本质上是「轮速与实际车速的差值」——这正是现实中轮胎打滑的定义，用在街机模型里效果很好。

### 撞击音效

由 `Sphere` 的 `body_entered` 信号触发，音量按车头方向（`basis.z`）的速度分量计算，所以侧面擦碰不会触发巨响：

```189:196:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
func _on_sphere_body_entered(_body: Node) -> void:
	
	if vehicle_body == null: return
	
	if not impact_sound.playing:
		var impact_velocity := absf(linear_velocity.dot(vehicle_body.global_basis.z))
		impact_sound.volume_db = clampf(remap(impact_velocity, 0.0, 6.0, -20.0, 0.0), -20.0, 0.0)
		impact_sound.play()
```

## 四、如何扩展成摩托车

`vehicle-motorcycle.gd` 继承自 `Vehicle`，只重写了两个方法：

```15:24:d:/gproject/Starter-Kit-Racing/scripts/vehicle-motorcycle.gd
func effect_body(delta):
	
	var target_lean = -input.x / 5 * linear_speed 
	calculated_lean = lerp_angle(calculated_lean, target_lean, delta * 5)
	
	# Apply leaning when doing corners
	
	if motorcycle != null:
		motorcycle.rotation.z = lerp_angle(motorcycle.rotation.z, input.x * linear_speed , delta * 3)
		vehicle_body.rotation.x = lerp_angle(vehicle_body.rotation.x, -(linear_speed - acceleration) / 6, delta * 10)
```

关键差异：

- 汽车是「车身侧倾」，摩托车是**整车压弯**（`motorcycle.rotation.z`），这是两者观感上最大的区别；
- 车轮只有前后两个，且前轮转向要连带动 `fork`（前叉）一起转；
- `_ready` 中重新指定了 `vehicle_body` 的路径，因为摩托车模型层级更深：

```9:11:d:/gproject/Starter-Kit-Racing/scripts/vehicle-motorcycle.gd
func _ready():
	
	vehicle_body = $Container/Model/motorcycle/body
```

## 五、这套方案的取舍

| 优点 | 局限 |
| --- | --- |
| 代码极少（< 200 行） | 没有真实漂移物理 |
| 参数直观、好调 | 空中仍会施加动力（见 [已知问题](08-已知问题与改进建议.md)） |
| 高速稳定，不会像 `VehicleBody3D` 那样抖动 | 无法模拟不同轮胎/路面抓地力差异 |
| 换模型零成本 | 碰撞体始终是球，与车外形无关 |

如果你的目标是**街机/卡丁车风格**（马里奥赛车那种），这套方案非常合适；如果需要**拟真赛车**（抓地力、重量转移、悬挂行程），则应改用 `VehicleBody3D` 或自己实现射线悬挂。
