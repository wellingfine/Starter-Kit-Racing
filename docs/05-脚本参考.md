### 节点引用

在 `_Ready()` 中统一获取：可选部件用 `GetNodeOrNull<T>()` 并在使用时判空——这是本项目「换模型零成本」的基础：

		_sphere = GetNode<RigidBody3D>("Sphere");
		_raycast = GetNode<RayCast3D>("Ground");

		_vehicleModel = GetNode<Node3D>("Container");
		VehicleBody = GetNodeOrNull<Node3D>("Container/Model/body");

		WheelFl = GetNodeOrNull<Node3D>("Container/Model/wheel-front-left");

> 注意：三个音效节点用 `GetNode<T>` 直接取，**没有判空**，属于必选件。新建载具场景时这三个节点必须存在。

### 状态字段

| 字段 | 类型 | 含义 | 可见性 |
| --- | --- | --- | --- |
| `_input` | `Vector3` | `X` = 转向（-1 左 / +1 右），`Z` = 油门（+1 前进 / -1 后退） | protected |
| `Normal` | `Vector3` | 地面法线 | protected |
| `LinearSpeed` | `float` | 虚拟速度标量（非物理速度） | **public**（相机要用） |
| `AngularSpeed` | `float` | 转向角速度（视觉） | protected |
| `Acceleration` | `float` | 混入角速度的加速度，驱动车轮与俯仰 | protected |
| `LinearVelocity` | `Vector3` | 由帧间位移反算的速度，仅用于撞击音量 | protected |
| `CalculatedLean` | `float` | 平滑后的侧倾值，参与漂移强度计算 | protected |
| `PrevPosition` | `Vector3` | 上一帧模型位置，用于反算线速度 | protected |
| `Colliding` | `bool` | 上一帧是否着地，用于检测「刚落地」 | protected |

> 只有 `LinearSpeed` 是 `public`（相机需要读它做镜头推拉）。将来如果要写 C# 子类，其余 `protected` 字段子类可直接访问。

### 主循环

`_PhysicsProcess(double delta)` 的执行顺序：

1. `HandleInput(step)` —— 采样输入并施加角速度
2. 计算转向目标并旋转视觉模型
3. 射线检测贴地并对齐法线
4. 更新 `LinearSpeed` / `Acceleration`
5. 同步视觉模型与射线到物理球位置
6. 反算 `LinearVelocity`
7. 依次调用 4 个 `Effect*` 方法

### 可扩展方法

全部是 `protected virtual`，C# 子类用 `override` 重写：

| 方法 | 默认行为 | 何时重写 |
| --- | --- | --- |
| `EffectEngine(float delta)` | 引擎音量/音调随速度与油门变化 | 换动力类型（如电动车无声） |
| `EffectBody(float delta)` | 车身俯仰 + 侧倾 + 回弹 | 两轮载具、飞行器 |
| `EffectWheels(float delta)` | 四轮自转 + 前轮转向 | 轮数不同（摩托 2 轮、坦克履带） |
| `EffectTrails()` | 漂移时发射烟雾并播放打滑声 | 换特效（水花、尘土） |
| `HandleInput(float delta)` | 采样 WASD/手柄并施加角速度 | 换操控方式（AI、触屏） |
| `AlignWithY(xform, newY)` | 基向量重建（static） | 一般不用动 |

> 说明：这些 `protected` 字段与 `virtual` 方法只对 C# 子类可见，新增载具请用 C# 写 `Vehicle` 的子类。

`scenes/vehicle.tscn` 中把 `Sphere.body_entered` 连接到 `_on_sphere_body_entered()`。新建载具场景时记得也要连上，否则没有撞击音效。方法名保持 snake_case 就是为了匹配这条连接。

## `View.cs`

```8:9:d:/gproject/Starter-Kit-Racing/scripts/View.cs
	[ExportGroup("Properties")]
	[Export] public Vehicle Target { get; set; } = null!;
```

```20:36:d:/gproject/Starter-Kit-Racing/scripts/View.cs
	public override void _PhysicsProcess(double delta)
	{
		// Ease position towards target vehicle position

		Position = Position.Lerp(Target.GetVehiclePosition(), (float)delta * 4);

		// Zoom camera based on the speed of the vehicle

		float speed_factor = Mathf.Clamp(Mathf.Abs(Target.LinearSpeed), 0.0f, 1.0f);
		float target_z = Mathf.Remap(speed_factor, 0.0f, 1.0f, 10.0f, 20.0f);

		_camera.Position = new Vector3(
			_camera.Position.X,
			_camera.Position.Y,
			Mathf.Lerp(_camera.Position.Z, target_z, (float)delta * 0.5f)
		);
	}
```

两个要点：

1. **只跟随位置，不跟随旋转**。相机自身不跟着车转，所以在弯道和甩尾时画面稳定，这是街机赛车常见的处理。
2. **按速度拉远镜头**（z 从 10 到 20）。镜头距离是速度感的重要来源，比加 FOV 更自然。

⚠️ `Target` 是 `[Export]` 属性，**未赋值时 `_PhysicsProcess` 会直接崩溃**。换载具后务必重新指定，见 [快速开始](02-快速开始.md)。

> 导出属性名是 `Target`（首字母大写），在编辑器检查器里按这个名字找。

## 新增一种载具的完整步骤

1. 复制 `scenes/vehicle.tscn` 为 `scenes/vehicle-xxx.tscn`。
2. 替换 `Container/Model` 为你的模型（保留必需的 `body` / `wheel-*` 子节点命名）。
3. 新建 `scripts/VehicleXxx.cs`，`public partial class VehicleXxx : Vehicle`，按需 `override` 各 `Effect*` 方法；若重写 `_Ready()` 记得先 `base._Ready()`。
4. 把新脚本挂到场景根节点，确认 `Sphere.body_entered` 信号仍连接着。
5. **项目 → 构建**，让新类进入程序集。
6. 实例化到主场景，并把 `View` 的 `Target` 指向它。
