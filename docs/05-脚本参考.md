## `vehicle.gd`

```1:1:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
class_name Vehicle extends Node3D
```

使用 `class_name` 注册为全局类，因此其它脚本可以直接用 `Vehicle` 作为类型标注（`view.gd` 就依赖这一点）。

### 节点引用

所有子节点引用都用 `@onready` + `get_node_or_null`，缺失时返回 `null` 并在使用时判空——这是本项目「换模型零成本」的基础：

```10:18:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
@onready var vehicle_model = $Container
@onready var vehicle_body = get_node_or_null("Container/Model/body")

# (Optional) wheels

@onready var wheel_fl = get_node_or_null("Container/Model/wheel-front-left")
@onready var wheel_fr = get_node_or_null("Container/Model/wheel-front-right")
@onready var wheel_bl = get_node_or_null("Container/Model/wheel-back-left")
@onready var wheel_br = get_node_or_null("Container/Model/wheel-back-right")
```

> 注意：三个音效节点用的是 `$Container/...` 直接取，**没有判空**，属于必选件。如果你新建载具场景，这三个节点必须存在。

### 状态变量

| 变量 | 含义 |
| --- | --- |
| `input` | `Vector3`，`x` = 转向（-1 左 / +1 右），`z` = 油门（+1 前进 / -1 后退） |
| `normal` | 地面法线 |
| `linear_speed` | 虚拟速度标量（非物理速度） |
| `angular_speed` | 转向角速度（视觉） |
| `acceleration` | 混入角速度的加速度，驱动车轮与俯仰 |
| `linear_velocity` | 由帧间位移反算的速度，仅用于撞击音量 |
| `calculated_lean` | 平滑后的侧倾值，参与漂移强度计算 |
| `colliding` | 上一帧是否着地，用于检测「刚落地」 |

### 公开 API

```47:47:d:/gproject/Starter-Kit-Racing/scripts/vehicle.gd
func get_vehicle_position() -> Vector3: return vehicle_model.global_position
```

供 `view.gd` 调用。注意返回的是**视觉模型**的位置而非物理球，这样相机跟随不会受球体翻滚影响。

### 主循环

`_physics_process` 的执行顺序：

1. `handle_input(delta)` —— 采样输入并施加角速度
2. 计算转向目标并旋转视觉模型
3. 射线检测贴地并对齐法线
4. 更新 `linear_speed` / `acceleration`
5. 同步视觉模型与射线到物理球位置
6. 反算 `linear_velocity`
7. 依次调用 4 个 `effect_*` 方法

### 可扩展方法

| 方法 | 默认行为 | 何时重写 |
| --- | --- | --- |
| `effect_engine(delta)` | 引擎音量/音调随速度与油门变化 | 换动力类型（如电动车无声） |
| `effect_body(delta)` | 车身俯仰 + 侧倾 + 回弹 | 两轮载具、飞行器 |
| `effect_wheels(delta)` | 四轮自转 + 前轮转向 | 轮数不同（摩托 2 轮、坦克履带） |
| `effect_trails()` | 漂移时发射烟雾并播放打滑声 | 换特效（水花、尘土） |
| `handle_input(delta)` | 采样 WASD/手柄并施加角速度 | 换操控方式（AI、触屏） |
| `align_with_y(xform, new_y)` | 基向量重建 | 一般不用动 |

### 信号连接

`scenes/vehicle.tscn` 中把 `Sphere.body_entered` 连接到 `_on_sphere_body_entered()`。新建载具场景时记得也要连上，否则没有撞击音效。

## `view.gd`

```10:21:d:/gproject/Starter-Kit-Racing/scripts/view.gd
func _physics_process(delta):
	
	# Ease position towards target vehicle position
	
	self.position = self.position.lerp(target.get_vehicle_position(), delta * 4)

	# Zoom camera based on the speed of the vehicle
	
	var speed_factor = clamp(abs(target.linear_speed), 0.0, 1.0)
	var target_z = remap(speed_factor, 0.0, 1.0, 10, 20)
	
	camera.position.z = lerp(camera.position.z, target_z, delta * 0.5)
```

两个要点：

1. **只跟随位置，不跟随旋转**。相机自身不跟着车转，所以在弯道和甩尾时画面稳定，这是街机赛车常见的处理。
2. **按速度拉远镜头**（z 从 10 到 20）。镜头距离是速度感的重要来源，比加 FOV 更自然。

⚠️ `target` 是 `@export` 变量，**未赋值时 `_physics_process` 会直接崩溃**。换载具后务必重新指定，见 [快速开始](02-快速开始.md)。

## 新增一种载具的完整步骤

1. 复制 `scenes/vehicle.tscn` 为 `scenes/vehicle-xxx.tscn`。
2. 替换 `Container/Model` 为你的模型（保留必需的 `body` / `wheel-*` 子节点命名）。
3. 新建 `scripts/vehicle-xxx.gd`，`extends Vehicle`，按需重写 `effect_*`。
4. 把新脚本挂到场景根节点，确认 `Sphere.body_entered` 信号仍连接着。
5. 实例化到主场景，并把 `View.target` 指向它。
