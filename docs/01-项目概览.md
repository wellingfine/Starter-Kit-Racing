# 01 - 项目概览

## 项目定位

Starter Kit Racing 是 Kenney 出品的 Godot 4.6 赛车游戏**起步模板**。它的目标是提供一套开箱即用的「驾驶手感 + 赛道搭建」最小可玩方案，**并不包含比赛逻辑**（无圈数、计时、检查点、AI 对手、名次）。

## 技术规格

| 项目 | 值 |
| --- | --- |
| 引擎版本 | Godot 4.6 |
| 渲染器 | Forward Plus |
| 物理引擎 | Jolt Physics |
| 脚本语言 | GDScript（项目不含 C#，无 `.csproj`） |
| 主场景 | `res://scenes/main.tscn` |
| 窗口分辨率 | 1280 × 720 |
| 代码规模 | 3 个脚本，约 220 行 |
| 代码许可 | MIT |
| 素材许可 | CC0 |

## 整体架构

```
Main (Node3D)
├── Environment        WorldEnvironment，天空/SSAO/SSIL/Glow
├── Plane              StaticBody3D，60×60 的无摩擦兜底地面
├── View               Node3D + Camera3D，跟随相机
├── Sun                DirectionalLight3D
├── GridMap            赛道本体，用 MeshLibrary 摆放地块
├── vehicle-truck-*    三辆纯装饰的静态卡车
└── Vehicle            玩家载具（scenes/vehicle.tscn 实例）
```

`Vehicle` 的内部结构是理解整个项目的关键：

```
Vehicle (Node3D)  ← scripts/vehicle.gd
├── Ground         RayCast3D，向下探测地面法线
├── Container      Node3D，纯视觉，跟随物理球
│   ├── Model              车模型（body + 4 个 wheel-*）
│   ├── TrailLeft/Right    GPUParticles3D，轮胎烟雾
│   └── Screech/Engine/ImpactSound   三个 AudioStreamPlayer3D
└── Sphere         RigidBody3D，真正的物理体
```

## 设计亮点

1. **绕开了 `VehicleBody3D`**。项目没有使用 Godot 内置的车辆节点，而是自创了一套「球体代理」方案：用一个 `RigidBody3D` 球做物理，视觉模型只负责跟随。不到 200 行代码就实现了稳定、好调的街机手感。详见 [车辆系统](04-车辆系统.md)。

2. **扩展点设计干净**。`vehicle.gd` 把「车身姿态」「车轮转动」等表现逻辑拆成 4 个可重写的 `effect_*` 方法，摩托车只需 39 行代码、重写其中 2 个方法就能完全改换操控表现。

3. **模型引用全部可选**。轮子、车身都用 `get_node_or_null` 获取并判空，缺件不会崩溃，方便替换任意模型。

## 与官方模板的差异

- 使用 Jolt Physics 而非 Godot Physics（项目设置中指定）。
- 启用了较高的画质配置（MSAA 2×、SSAO quality 3、SSIL、Glow），低端设备需要降配，详见 [项目设置](07-项目设置.md)。
