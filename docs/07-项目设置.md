# 07 - 项目设置

`project.godot` 中值得关注的几组配置。

## 基础信息

```13:19:d:/gproject/Starter-Kit-Racing/project.godot
config/name="Starter Kit Racing"
config/tags=PackedStringArray("starterkit")
run/main_scene="res://scenes/main.tscn"
config/features=PackedStringArray("4.8", "Forward Plus")
boot_splash/bg_color=Color(0.921875, 0.921875, 0.957031, 1)
boot_splash/image="res://splash-screen.png"
config/icon="res://icon.png"
```

`config/features` 声明了引擎版本 4.8 与 Forward Plus 渲染器。

## .NET（C#）

```26:28:d:/gproject/Starter-Kit-Racing/project.godot
[dotnet]

project/assembly_name="Starter Kit Racing"
```

项目脚本语言是 C#，工程文件为根目录的 `Starter Kit Racing.csproj`（`Godot.NET.Sdk` / `net10.0`）。程序集名与项目同名，构建产物输出到 `.godot/mono/temp/bin/`。

> Godot 编辑器会在构建时**重写 `.csproj`**（例如补 `RootNamespace`、调整 `TargetFramework` 平台分支）。因此项目级编译开关不要写进 `.csproj`，需要 `Nullable` 这类开关时在 `.cs` 文件顶部用 `#nullable enable` 声明。

| --- | --- | --- |
| `forward` | <kbd>W</kbd> / <kbd>↑</kbd> | 右扳机（axis 5） |
| `back` | <kbd>S</kbd> / <kbd>↓</kbd> | 左扳机（axis 4） |
| `left` | <kbd>A</kbd> / <kbd>←</kbd> | 左摇杆 X 负向（axis 0） |

> ⚠️ **`bounce` 动作目前没有任何脚本使用**，属于死配置。详见 [已知问题](08-已知问题与改进建议.md)。

## 物理

```243:245:d:/gproject/Starter-Kit-Racing/project.godot
[physics]

3d/physics_engine="Jolt Physics"
```

使用 Jolt Physics 而非默认的 Godot Physics。Jolt 在高速物体和堆叠稳定性上表现更好，这正好契合本项目的球体方案。

> 注意：Jolt 与 Godot Physics 在碰撞余量、接触冲量等行为上有差异。如果你把项目改成 Godot Physics，车辆手感可能明显变化，需要重新调参。

## 渲染

| 设置 | 值 |
| --- | --- |
| `anti_aliasing/quality/msaa_3d` | 2（2× MSAA） |
| `lights_and_shadows/directional_shadow/soft_shadow_filter_quality` | 3 |
| `environment/ssao/quality` | 3 |
| `environment/ssao/half_size` | false（全分辨率 SSAO） |
| `environment/ssao/fadeout_from` / `to` | 500 / 2000 |

这是一套**偏重的画质配置**。如果要移植到移动端或低端设备，建议优先关闭 `ssao/half_size=false`（改为 true）、降低 `ssao/quality` 和 `msaa_3d`。

## 文件系统

```35:37:d:/gproject/Starter-Kit-Racing/project.godot
[filesystem]

import/fbx/enabled=false
```

禁用了 FBX 的运行时导入。这意味着：

- `.fbx` 文件仍然可以在编辑器里用作**导入源**（例如烘焙碰撞网格）；
- 但导出的游戏中不能再动态加载 `.fbx`。

对本模板无影响，但如果你要加入运行时下载/加载 FBX 的功能，需要把这项打开。

## 启动画面（Boot Splash）

这是 Godot 的**引擎级内置功能**，不需要任何代码或场景节点。整个项目中与 splash 相关的配置只有这两行：

```17:18:d:/gproject/Starter-Kit-Racing/project.godot
boot_splash/bg_color=Color(0.921875, 0.921875, 0.957031, 1)
boot_splash/image="res://splash-screen.png"
```

### 工作原理

引擎在 `main_scene` 加载**之前**的启动阶段，由 `Main` 直接绘制这张图。它不走场景树，所以你在 `main.tscn` 里找不到任何相关节点。

### Application → Boot Splash 全部设置

| 设置 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `image` | String（路径） | 空 | 留空则显示 Godot 官方 logo。**仅支持 PNG**，其它格式会报错 |
| `bg_color` | Color | `Color(0.14,0.14,0.14,1)` 深灰 | 图片未铺满时的背景填充色 |
| `show_image` | bool | `true` | 关闭则只显示纯 `bg_color` |
| `stretch_mode` | int | `1`（keep） | 禁用 / 保持 / 保持宽 / 保持高 / 覆盖 / 忽略 |
| `use_filter` | bool | `true` | 线性过滤（高清图）vs 最近邻（像素画） |
| `minimum_display_time` | int（毫秒） | `0` | 最短展示时间，官方不建议设太高 |

本项目只覆盖了前两项：把 `bg_color` 从默认的深灰改成近白 `Color(0.92, 0.92, 0.96)`，以匹配 Kenney 那张浅色底的品牌图，避免窗口边缘露出深色框。

### 两个实践要点

1. **编辑器里也会显示**。`image` 对编辑器同样生效——用 Godot 打开这个项目时，加载画面就是这张图。若希望只在导出版显示自定义图、编辑器仍显示 Godot 官方 logo，需要为 `editor_hint` 这个 feature tag 添加一个空 override。

2. **可能一闪而过**。本项目 `minimum_display_time` 为默认 0，而资源量小、加载极快，所以 splash 基本瞬间消失。想让玩家看清就把它设成 `1000`（1 秒）左右——但不宜更长，否则会拖慢启动体验。
